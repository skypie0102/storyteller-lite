# StoryTeller Lite v0.2.0-beta.1

Windows x64 prerelease of the rebuilt Rust + Slint app, including the latest long-audio and progress work from PRs #32–34. This beta is for testing on real hardware and complete English audiobooks. Main and the v0.1.0 stable release remain unchanged.

## Included

- Rebuilt New book, Queue and Settings UI. Dark is the default; Light is available in Settings → Appearance → Theme and your choice is saved.
- Lightweight English-only Whistle CPU transcription. Automatic recommends workers from CPU/RAM; manual selection supports 1–16 workers.
- Optional Whisper Turbo Q5 for NVIDIA GPUs. One GPU worker handles up to eight sequential inputs per model load, with live overall and per-part progress.
- Whistle inputs stay within its 30-second cap. Whisper uses roughly five-minute inputs with internal model windows. Both paths overlap audio context and reconcile native word times across boundaries.
- Seven-stage audiobook/EPUB processing, durable audio review, verified cache recovery, and independently validated EPUB publication.
- Portable executable with build provenance and SHA-256 checksums. Runtime/model downloads remain optional, verified and stored per user.

## Install and start

1. Download **StoryTeller-Lite-v0.2.0-beta.1-windows-x64.zip**, extract it, and run **StoryTeller-Lite.exe**.
2. Open **Settings**. For Whistle, use **Download missing**, then leave workers on **Automatic** for your first run.
3. For an NVIDIA GPU, choose **Whisper Turbo · NVIDIA GPU**, check setup, then select **Download Whisper tools**. The optional download is about 847 MB; allow 3 GB free disk space. The app currently requires at least 4 GiB free VRAM on the first NVIDIA GPU and rejects CPU fallback.
4. In **New book**, select a matching English EPUB and audiobook, choose an output folder, and start processing. Resolve any **Review Audio** items before continuing.

The executable is unsigned, so Windows may show a SmartScreen prompt. You can compare the ZIP hash with the supplied `.sha256` file:

```powershell
Get-FileHash .\StoryTeller-Lite-v0.2.0-beta.1-windows-x64.zip -Algorithm SHA256
```

## Please test

Start with a short matching book, then try a complete multi-hour audiobook. Check progress, review decisions, cancellation and paused recovery after closing/reopening the app. Open the finished EPUB in your preferred Media Overlay reader and check narration/highlighting near chapter and audio boundaries and near the end of the book.

If you have a compatible NVIDIA GPU, compare the same book with Whistle and Whisper. Report Windows version, CPU/RAM, GPU/VRAM and driver, selected engine/workers, audio duration, processing time, and any error or unexpected behavior. For playback issues, include the reader/version and the affected passage/time; sharing copyrighted source books is unnecessary.

## Known beta limits

The automated Windows gate covers formatting, strict workspace lint/tests, native Dark/Light UI interactions, release packaging, checksums and packaged paused recovery. Earlier pinned native-engine checks cover real Whistle, Turbo JSON/model reuse, long inputs, cut-word reconciliation, live decoder callbacks and rejected GPU fallback on a CPU-hosted runner. Real NVIDIA throughput/VRAM, representative full-book quality and reader playback still need your testing; no GPU speed claim is made.

GPU support currently targets Windows x64 NVIDIA only, with one GPU worker and the first GPU in PCI order. AMD/Intel/Vulkan, multiple GPUs and whole-book model residency are pending. English is the only application-supported language. This portable beta has no installer or auto-update channel.
